# Vendor Performance Dashboard

## Overview
Interactive Excel dashboard developed to analyze supplier performance and procurement metrics.

## Key Features
- Vendor Scorecard
- On-Time Delivery (OTD) Analysis
- Quality Rate Monitoring
- Fill Rate Tracking
- ABC Spend Analysis
- Supplier Risk Analysis
- Dynamic KPI Dashboard

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Data Visualisation

## Project Objective
To improve supplier performance visibility and support procurement decision-making through data analytics.

## Dataset
This project uses a sample procurement dataset containing 500+ supplier transactions created for learning and portfolio purposes.

## Key Metrics
- On-Time Delivery (OTD)
- Quality Rate
- Fill Rate
- Vendor Score
- Total Spend
- Average OTD
- Supplier Count

## Key Insights
- Top 6 suppliers account for approximately 66% of total spend.
- Vertex Solutions achieved the highest vendor performance score.
- Omega Industries recorded the lowest On-Time Delivery performance.
- ABC analysis identified high-spend suppliers requiring closer monitoring.
- Supplier Risk Matrix helps identify vendors requiring corrective actions.
