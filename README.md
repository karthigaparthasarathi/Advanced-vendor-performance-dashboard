# Vendor Performance Dashboard

## Overview
Interactive Excel dashboard developed to analyze supplier performance and procurement metrics.

## Key Features
- Vendor Scorecard
- On-Time Delivery (OTD) Analysis
- Quality Rate Monitoring
- Fill Rate Tracking
- ABC Spend Analysis
- Supplier risk Analysis
- Dynamic KPI Dashboard

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Data Visualisation
